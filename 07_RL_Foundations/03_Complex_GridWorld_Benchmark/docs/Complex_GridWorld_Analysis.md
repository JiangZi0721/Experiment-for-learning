## 🗺️ 第一部分：复杂环境架构与物理规则

为了打破简单网格中“单调距离衰减”的平庸现象，本项目设计了一个融合**双终点博弈**与**梯度阶梯危险**的高维决策网格环境。

```
+-------------------------------------------------------------+
|  (0,0) START   |  (0,1) 平原     |  (0,2) 分岔桥   |  (0,3) 次级目标  |
|  [步长: -1.0]  |  [步长: -1.0]   |  [步长: -1.0]   |  [奖励: +3.0] 🏁 |
+----------------+-----------------+-----------------+-----------------+
|  (1,0) 安全走廊 |  (1,1) 决策枢纽 |  (1,2) 熔岩巨坑 |  (1,3) 悬崖过道  |
|  [步长: -1.0]  |  [步长: -1.0]   |  [惩罚: -10.0]🔥|  [步长: -1.0]   |
+----------------+-----------------+-----------------+-----------------+
|  (2,0) 安全走廊 |  (2,1) 流沙泥潭 |  (2,2) 危险前哨 |  (2,3) 尖刺陷阱  |
|  [步长: -1.0]  |  [惩罚: -3.0]⚠️ |  [步长: -1.0]   |  [惩罚: -6.0]🗡️ |
+----------------+-----------------+-----------------+-----------------+
|  (3,0) 绕行转角 |  (3,1) 冲锋走廊 |  (3,2) 终点门槛 |  (3,3) 终极大奖  |
|  [步长: -1.0]  |  [步长: -1.0]   |  [步长: -1.0]   |  [奖励: +10.0]🏆|
+-------------------------------------------------------------+
```

### 1. 复杂地形与奖励矩阵设计

1. **双终点设定 (Dual Terminal Goals)**：
   * **安全次级目标 (Sub-Goal) `(0, 3)`**：终端吸收态，获得奖励 **$+3.0$**。距起点仅 3 步且路径平坦无陷阱，为保守型智能体提供“落袋为安”的安全出口。
   * **终极宝藏大奖 (Main Goal) `(3, 3)`**：终端吸收态，获得奖励 **$+10.0$**。奖金极高，但通往此处的捷径被多个致命陷阱重重包围。
2. **多层阶梯式危险陷阱 (Multi-Tier Hazards，非终止进入扣分)**：
   * **致命熔岩坑 (Lava Pit) `(1, 2)`**：踏入惩罚 **$-10.0$**。中心毁灭性陷阱。
   * **尖刺陷阱 (Spike Trap) `(2, 3)`**：踏入惩罚 **$-6.0$**。卡在终极大奖正上方的咽喉要道。
   * **流沙泥潭 (Quicksand Swamp) `(2, 1)`**：踏入惩罚 **$-3.0$**。中等障碍，减速并扣分。
3. **标准单步物理能耗 (Step Cost)**：
   * 走动进入任意常规网格或发生边界撞墙阻挡，扣除惩罚 **$-1.0$**。

### 2. 关键超参数设定
* 折扣因子 $\gamma = 0.9$
* 学习率（更新步长） $\alpha = 0.1$
* 探索率 $\epsilon = 0.1$ ($\epsilon$-贪婪探索)
* 动作空间 $\mathcal{A} = \{ \text{UP (0)}, \text{DOWN (1)}, \text{LEFT (2)}, \text{RIGHT (3)} \}$，确定性物理转移（撞墙反弹停在原地）。

## 📐 第二部分：动态规划基准——理论最优解 (Value Iteration)

在分析无模型算法之前，我们先通过价值迭代精确解出该环境的贝尔曼最优状态价值 $V^*(s)$ 与最优策略 $\pi^*(s)$，作为检验无模型学习效果的理论金标准：

$$V^*(s) = \max_{a \in \mathcal{A}} \sum_{s', r} P(s', r | s, a) \big[ r + \gamma V^*(s') \big]$$

#### 理论最优状态价值矩阵 $V^*(s)$
```
Row 0: [  +1.81    +1.70    +3.00    +0.00(Term) ]
Row 1: [  +3.12    +2.58    +6.20    +3.00       ]
Row 2: [  +4.58    +6.20    +8.00   +10.00       ]
Row 3: [  +6.20    +8.00   +10.00    +0.00(Term) ]
```

#### 理论最优策略 $\pi^*(s)$ 矢量场
* 起点 `(0, 0)` 最优动作为 **DOWN (↓)**：虽然向右去次级目标更快，但最优全局解是沿着左侧外环安全走廊绕过熔岩和泥潭：$(0,0) \to (1,0) \to (2,0) \to (3,0) \to (3,1) \to (3,2) \to (3,3)$。
* 最优期望回报为：
  $$G^* = -1 + 0.9(-1) + 0.9^2(-1) + 0.9^3(-1) + 0.9^4(-1) + 0.9^5(10) = -4.0951 + 5.9049 = \mathbf{+1.8098}$$
  这严格高于前往次级目标的净回报（$-1 - 0.9 + 0.9^2 \times 3 = +0.530$）！

## 🧪 第三部分：三大无模型算法真实运行结果全景比对

我们执行 [`experiments/exp4_complex_gridworld.py`](experiments/exp4_complex_gridworld.py) 进行真实物理仿真，输出无模型三剑客学习到的价值函数与贪婪策略。

### 1. TD(0) 状态价值估计 (随机策略)
在均匀随机策略 $\pi(a|s) = 0.25$ 下，智能体在全图盲目游走并由 TD(0) 递推评估：
$$V(S) \leftarrow V(S) + \alpha \big[ R + \gamma V(S') - V(S) \big]$$

```
TD(0) 收敛状态价值 V(s):
Row 0: [ -11.37   -12.23    -8.91    +0.00 ]
Row 1: [ -12.41   -15.44   -11.32    -8.17 ]
Row 2: [ -11.87   -10.88   -11.37    -4.59 ]
Row 3: [ -10.36    -9.50    -1.57    +0.00 ]
```
* **物理特征**：由于是纯随机乱走，智能体极高概率踩入熔岩 (-10.0) 和尖刺 (-6.0)，全图大部分状态价值深度陷入负值区间。
* 靠近终极大奖的门槛 `(3, 2)` 价值最高（$-1.57$），而紧贴熔岩坑的枢纽 `(1, 1)` 价值最低（$-15.44$），形成了强烈的负价值深渊。

### 2. SARSA 同策略控制 (知行合一的谨慎避险)
SARSA 采用同策略 $\epsilon$-贪婪控制，单步更新充分考虑自身未来的探索风险：
$$Q(S, A) \leftarrow Q(S, A) + \alpha \big[ R + \gamma Q(S', A') - Q(S, A) \big]$$

```
SARSA 收敛 Max Q(s, a):
Row 0: [  +0.02    +1.30    +3.00    +0.00 ]
Row 1: [  -0.86    +0.20    +1.69    +0.57 ]
Row 2: [  -0.77    -0.16    +0.63    +1.00 ]
Row 3: [  -0.40    +1.31    +6.51    +0.00 ]

SARSA 收敛贪婪策略矢量:
Row 0: [   →        →        →      GOAL   ]
Row 1: [   ↑        ↑        ↑        ↑     ]
Row 2: [   ↑        →        ↓        ↓     ]
Row 3: [   →        →        →      GOAL   ]
```
* **避险行为**：在起点 `(0, 0)` 处，SARSA 的贪婪策略直接选择 **向右 (→)** 直奔安全次级目标 `(0, 3)`！因为如果向下走，$\epsilon=0.1$ 的随机探索可能导致滑入熔岩或泥潭；为了规避风险，SARSA 果断收敛到稳定获利的安全次级终点。

### 3. Q-Learning 异策略控制 (激进精准的最优解求解)
Q-Learning 使用贝尔曼最优算子，以 $\max_{a'} Q(S', a')$ 脱离当前探索行为进行自举：
$$Q(S, A) \leftarrow Q(S, A) + \alpha \big[ R + \gamma \max_{a'} Q(S', a') - Q(S, A) \big]$$

```
Q-Learning 收敛 Max Q(s, a):
Row 0: [  +0.53    +1.70    +3.00    +0.00 ]
Row 1: [  -0.53    +0.52    +1.69    +0.81 ]
Row 2: [  -0.58    -0.10    +0.21    +1.90 ]
Row 3: [  -0.35    +0.38    +4.69    +0.00 ]

Q-Learning 收敛贪婪策略矢量:
Row 0: [   →        →        →      GOAL   ]
Row 1: [   ↑        ↑        ↑        ↑     ]
Row 2: [   ↓        →        ↓        ↓     ]
Row 3: [   →        →        →      GOAL   ]
```
* **理论精度**：起点 `(0, 0)` 的向右价值精准收敛到 **$+0.53$**，与我们前文手工理论推导的次级目标回报 $+0.530$ **100% 绝对吻合**！

### 2. 【时间步 #1】TD(0) 发现次级目标：由负转正的局部引力场诞生

* **算法类别**：TD(0) 状态评估
* **发生节点**：Episode 8, Step 0
* **物理过程**：智能体在上一局盲走中积累了大量负价值，本回合起始于 `(0, 2)`，执行动作 **RIGHT (→)** 直接撞入次级目标 `(0, 3)`！

![时间步 #1: TD(0) 发现次级目标](images/step1_td0_subgoal_discovery.png)

#### 算术级代入推演
1. **当前状态与转移**：$S = (0, 2) \xrightarrow{A = \text{RIGHT}} S' = (0, 3)$（终端吸收态）。
2. **环境反馈**：即时奖励 $R = +3.0$；由于 $S'$ 为终点，其未来价值严格归零：$V(S') = 0.0$。
3. **更新前历史价值**：$V_{\text{old}}(0, 2) = -2.492$（前期在网格中漫游步数扣分所致）。
4. **单步自举 TD 目标**：
   $$\text{Target} = R + \gamma \cdot V(S') = 3.0 + 0.9 \times 0.0 = \mathbf{+3.000}$$
5. **时序差分误差 (TD Error)**：
   $$\delta = \text{Target} - V_{\text{old}}(S) = 3.000 - (-2.492) = \mathbf{+5.492}$$
6. **在线增量均值更新**：
   $$V_{\text{new}}(0, 2) \leftarrow -2.492 + 0.1 \times (+5.492) = \mathbf{-1.943}$$
7. **价值绝对变动量**：
   $$|\Delta V| = |-1.943 - (-2.492)| = \mathbf{0.549} \quad (\text{单步暴涨 } 22\%)$$

> [!NOTE]
> **RL 物理/策略意义**：
> 这一步是全图上边缘区域“价值由负转正”的破冰时刻。原本无序漫游积累的步数损耗被强力的 $+3.0$ 终点奖励阻断，在右上角首次确立了向终端汇聚的局部正向引力场。

### 3. 【时间步 #2】TD(0) 误入熔岩深坑：毁灭性惩罚的负向冲击波

* **算法类别**：TD(0) 状态评估
* **发生节点**：Episode 3, Step 11
* **物理过程**：智能体从 `(2, 2)` 向上盲走，误入致命熔岩坑 `(1, 2)`，遭受 $-10.0$ 极限制裁。

![时间步 #2: TD(0) 误入熔岩深坑](images/step2_td0_lava_pit_fall.png)

#### 算术级代入推演
1. **当前状态与转移**：$S = (2, 2) \xrightarrow{A = \text{UP}} S' = (1, 2)$（非终端熔岩格）。
2. **环境反馈**：获得严重惩罚 $R = -10.0$；后继状态价值初值为 $V(1, 2) \approx 0.0$。
3. **更新前历史价值**：$V_{\text{old}}(2, 2) = -1.021$。
4. **单步自举 TD 目标**：
   $$\text{Target} = R + \gamma \cdot V(S') = -10.0 + 0.9 \times 0.0 = \mathbf{-10.000}$$
5. **时序差分误差 (TD Error)**：
   $$\delta = \text{Target} - V_{\text{old}}(S) = -10.000 - (-1.021) = \mathbf{-8.979}$$
6. **在线增量均值更新**：
   $$V_{\text{new}}(2, 2) \leftarrow -1.021 + 0.1 \times (-8.979) = \mathbf{-1.919}$$
7. **价值绝对变动量**：
   $$|\Delta V| = |-1.919 - (-1.021)| = \mathbf{0.898} \quad (\text{单步断崖式下挫})$$

> [!WARNING]
> **RL 物理/策略意义**：
> 状态 `(2, 2)` 瞬间被环境惩罚染黑，成为危险过渡区。由于 TD(0) 是随机策略评估，随着后续采样，这个 $-8.979$ 的负向差分信号将如涟漪般扩散至邻近所有格子，拉低周边所有状态的平均生存估值。

### 4. 【时间步 #3】SARSA 首达终极大奖：全图动作价值的破晓奇点

* **算法类别**：SARSA 同策略控制
* **发生节点**：Episode 0, Step 38
* **物理过程**：首个回合在漫长的 38 步随机游走后，智能体在 `(3, 2)` 偶然执行了 **RIGHT (→)**，破天荒第一次撞入了终极大奖 `(3, 3)`！

![时间步 #3: SARSA 首达终极大奖](images/step3_sarsa_main_goal_discovery.png)

#### 算术级代入推演
1. **当前动作与转移**：$S = (3, 2), A = \text{RIGHT} \rightarrow S' = (3, 3)$（终极大奖）。
2. **环境反馈**：终点大奖 $R = +10.0$；终止态无后续动作：$Q(S', A') = 0.0$。
3. **更新前历史价值**：$Q_{\text{old}}((3, 2), \text{RIGHT}) = 0.000$（此前全图均为 0）。
4. **单步自举 TD 目标**：
   $$\text{Target} = R + \gamma \cdot 0.0 = \mathbf{+10.000}$$
5. **时序差分误差 (TD Error)**：
   $$\delta = \text{Target} - Q_{\text{old}}(S, A) = 10.000 - 0.000 = \mathbf{+10.000}$$
6. **动作价值函数更新**：
   $$Q_{\text{new}}((3, 2), \text{RIGHT}) \leftarrow 0.000 + 0.1 \times (+10.000) = \mathbf{+1.000}$$
7. **价值绝对变动量**：
   $$|\Delta Q| = \mathbf{1.000} \quad (\text{全图全流程单步理论最大更新幅度})$$

> [!IMPORTANT]
> **RL 物理/策略意义**：
> 这是整个动作价值空间的**奇点时刻**！在这一步之前，整个 Q 矩阵一片虚无；从这一步开始，$+1.000$ 成为全图最高的灯塔，在下一回合中，所有到达 `(3, 2)` 的动作都会被这个灯塔吸引，从而拉开控制策略向大奖收敛的序幕。

### 5. 【时间步 #4】SARSA 踩入尖刺陷阱：同策略体验驱逐危险动作

* **算法类别**：SARSA 同策略控制
* **发生节点**：Episode 68, Step 4
* **物理过程**：智能体在 `(2, 2)` 试图向右突进，踩入尖刺陷阱 `(2, 3)`，获得 $-6.0$ 惩罚。

![时间步 #4: SARSA 踩入尖刺陷阱](images/step4_sarsa_spike_trap_deterrence.png)

#### 算术级代入推演
1. **当前动作与转移**：$S = (2, 2), A = \text{RIGHT} \rightarrow S' = (2, 3)$（踩入尖刺陷阱）。
2. **环境反馈**：获得即时惩罚 $R = -6.0$；智能体在尖刺处按 $\epsilon$-贪婪采样下一动作 $A'$，其当前估计 $Q(S', A') \approx 0.0$。
3. **更新前历史价值**：$Q_{\text{old}}((2, 2), \text{RIGHT}) = 0.000$。
4. **单步自举 TD 目标**：
   $$\text{Target} = R + \gamma Q(S', A') = -6.0 + 0.9 \times 0.0 = \mathbf{-6.000}$$
5. **时序差分误差 (TD Error)**：
   $$\delta = \text{Target} - Q_{\text{old}}(S, A) = -6.000 - 0.000 = \mathbf{-6.000}$$
6. **动作价值函数更新**：
   $$Q_{\text{new}}((2, 2), \text{RIGHT}) \leftarrow 0.000 + 0.1 \times (-6.000) = \mathbf{-0.600}$$
7. **价值绝对变动量**：
   $$|\Delta Q| = \mathbf{0.600}$$

> [!TIP]
> **RL 物理/策略意义**：
> 在同策略架构下，智能体必须用“自己亲身尝试的下一个动作”来计算目标。向右的动作价值直接暴跌为 $-0.600$。由于基准动作为 0，这使得 $\arg\max_a Q((2, 2), a)$ 立即排除了“向右”选项，促使策略向其他方向探索。

### 6. 【时间步 #5】Q-Learning 异策略回传激增：Max 算子引发策略箭头大翻转

* **算法类别**：Q-Learning 异策略控制
* **发生节点**：Episode 180, Step 4
* **物理过程**：在 `(2, 2)` 处，虽然智能体之前已发现向右踩刺为负（$Q = -0.600$），但此时从 `(2, 2)` 向下移动到 `(3, 2)`，Q-Learning 的 $\max$ 算子敏锐捕捉到后方的黄金宝藏！

![时间步 #5: Q-Learning 异策略回传激增](images/step5_qlearning_bootstrap_surge.png)

#### 算术级代入推演
1. **当前动作与转移**：$S = (2, 2), A = \text{DOWN} \rightarrow S' = (3, 2)$。
2. **环境反馈**：常规单步损耗 $R = -1.0$。
3. **异策略最优价值探测**：
   在后继状态 $S' = (3, 2)$，由于右侧大奖的回传，$Q((3, 2), \text{RIGHT})$ 已经累积到 $+3.439$：
   $$\max_{a' \in \mathcal{A}} Q((3, 2), a') = \mathbf{+3.439}$$
4. **单步自举 TD 目标**：
   $$\text{Target} = R + \gamma \cdot \max_{a'} Q(S', a') = -1.0 + 0.9 \times 3.439 = \mathbf{+2.095}$$
5. **时序差分误差 (TD Error)**：
   $$\delta = \text{Target} - Q_{\text{old}}(S, A) = 2.095 - 0.000 = \mathbf{+2.095}$$
6. **动作价值函数更新**：
   $$Q_{\text{new}}((2, 2), \text{DOWN}) \leftarrow 0.000 + 0.1 \times 2.095 = \mathbf{+0.210}$$
7. **动作竞争格局逆转**：
   * 向下动作：$Q((2, 2), \text{DOWN}) = \mathbf{+0.210}$
   * 向右动作：$Q((2, 2), \text{RIGHT}) = \mathbf{-0.600}$（踩刺）
   * 结果：**贪婪策略箭头在这一瞬间彻底从向右翻转向下（↓）！**

> [!NOTE]
> **RL 物理/策略意义**：
> 这充分展现了 Q-Learning 的异策略精髓：**“无论你下一步是探索还是滑倒，我都假设你下一步会做出最聪明的选择”**。凭借 $\max$ 算子的穿透力，向下的动作单步冲正，彻底锁定了避开尖刺、直奔大奖的最优战术路径。

### 7. 【时间步 #6】Q-Learning 熔岩死刑一票否决：安全拓扑硬边界的锁定

* **算法类别**：Q-Learning 异策略控制
* **发生节点**：Episode 1, Step 16
* **物理过程**：在关键十字路口 `(1, 1)`，智能体向右误撞中心熔岩巨坑 `(1, 2)`。

#### 算术级代入推演

2. **环境反馈**：获得惩罚 $R = -10.0$；$S'$ 的 $\max Q = 0.0$。
3. **更新前历史价值**：$Q_{\text{old}}((1, 1), \text{RIGHT}) = 0.000$。
4. **单步自举 TD 目标**：

   $$\delta = -10.000 - 0.000 = \mathbf{-10.000}$$

## 🥊 第五部分：复杂多奖惩下的本质机制横向剖析

### 1. 次级安全目标 (+3.0) vs 终极高难大奖 (+10.0) 的博弈

在简单网格中，智能体只有一个目标，算法好坏仅体现为收敛快慢。而在本多目标环境中，算法面临了深刻的**收益与风险折衷 (Risk-Reward Trade-off)**：
* **次级目标**：收益仅为 $+3.0$，但路线平坦，方差极小。
* **终极目标**：收益高达 $+10.0$，但路线上必须经过熔岩与泥潭边缘，动作稍有偏差即遭毁灭性扣分。

### 2. SARSA 畏惧陷阱 vs Q-Learning 刀尖起舞的数学根源

在实验中，我们观察到 SARSA 在起点处坚定不移地选择走向安全次级目标 `(0, 3)`，而 Q-Learning 在多次探索后能够准确给出底层大奖的更高潜在价值：
1. **SARSA 的目标函数**：
   $$\mathbb{E}_{\pi_{\epsilon}} \big[ R + \gamma Q(S', A') \big]$$
   由于存在 $\epsilon = 0.1$ 的随机探索概率，智能体在险峻道路上走动时，**必须把“自己手滑摔入熔岩”的概率期望折算进动作价值中**。因此在险道上，动作价值会受到剧烈惩罚，使得危险捷径的期望回报甚至不如平坦小道。
2. **Q-Learning 的目标函数**：
   $$R + \gamma \max_{a'} Q(S', a')$$
   Q-Learning 的更新目标假设后继动作**永远执行确定性的最优动作**，完全忽略了实际交互时的 $\epsilon$-滑动风险。它学到的是纯粹的物理最优极限。

### 3. TD、SARSA 与 Q-Learning 核心更新机制全维度对比表

| 维度 | TD(0) 状态评估 | SARSA 同策略控制 | Q-Learning 异策略控制 |
| :--- | :--- | :--- | :--- |
| **估计对象** | 状态价值 $V(s)$ | 动作价值 $Q(s, a)$ | 动作价值 $Q(s, a)$ |
| **自举目标算子** | $R + \gamma V(S')$ | $R + \gamma Q(S', A')$ | $R + \gamma \max_{a'} Q(S', a')$ |
| **策略类型** | 固定策略 (如随机游走) | 同策略 (On-Policy) | 异策略 (Off-Policy) |
| **下一个动作来源** | 无需动作（评估状态） | 行为策略实际采样的 $A'$ | 贪婪假想的 $\arg\max_{a'} Q(S', a')$ |
| **探索风险态度** | 被动承受全图危险 | **高风险敏感（极度保守）** | **风险中性（激进寻优）** |
| **面对本实验复杂陷阱** | 价值全图深度泛红崩溃 | 避开下半区，全军撤向安全次级目标 | 准确算出次级目标与主目标的精确极限解 |
