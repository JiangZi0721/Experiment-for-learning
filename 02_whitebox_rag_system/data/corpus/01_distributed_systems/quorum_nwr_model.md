# Quorum NWR 调谐模型与可调节一致性

## 1. 参数定义
- $N$：数据副本总数。
- $W$：写操作成功所必须确认的最小副本数。
- $R$：读操作成功所必须读取的最小副本数。

## 2. 鸽巢原理与一致性保证
- **强一致性 (Strong Consistency)**：当 $W + R > N$ 时，读集合与写集合必然存在至少一个重叠节点。结合版本号即可识别出最新提交的数据。
- **写优化配置**：$W=1, R=N$。写极快且高可用，但读性能严重下降。
- **读优化配置**：$W=N, R=1$。读操作只需访问任意单个节点即可，但写操作必须全员存活。
- **对称折中配置**：$W = \lfloor N/2 floor + 1, R = \lfloor N/2 floor + 1$，典型 Quorum 多数派。
