## 模块导览

本知识库旨在打通从**经典机器学习 (Machine Learning)** 到**深度神经网络 (Deep Learning)** 的底层认知跃迁。不仅关注“怎么调包”，更直击矩阵微积分、自动微分（反向传播）拓扑图、非凸优化景观、梯度流动控制、正则归一化机理及各架构的归纳偏置（Inductive Bias）。

### 核心文档索引

- [自编码器与无监督表征学习全景 (Autoencoders Master)](./Autoencoders_and_Representation_Learning_Master.md)：涵盖欠完备自编码器、PCA 线性等价性证明、高维非线性流形假设、信息瓶颈理论与正交去噪投影的微观几何白盒解析。
