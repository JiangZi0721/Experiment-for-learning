>

## 🛠️ 项目通用规范与理念

本仓库下的每一个子实验项目，均严格保证：
1. **白盒可透视 (White-box Transparency)**：避免使用高级深度学习框架的开箱封装，关键层（如前向切片、反向传播原子累加、损失计算）均由底层向量化代码实现。
2. **严密的数学推导 (Mathematical Rigor)**：代码仓库均配套详尽的 Markdown 文档，从似然函数目标推导至梯度解析解。
3. **独立自包含 (Self-contained)**：每个子目录均为一个功能完备的独立子工程，包含完整的测试、验证与交互工具，互不干扰，即拉即跑。
